# projet_econometrie
Projet visant à trouver des facteurs explicatifs de l'espérance de vie.

On a développé un modèle à 4 variables dont 3 exogènes : richesse par habitant, niveau d'éducation, indicatrice d'inégalité calculé grace à l'indice de GINI

On trouve que toutes ces variables sont explicative et nous avons apporté des corrections afin d'améliorer leur explicativité.
